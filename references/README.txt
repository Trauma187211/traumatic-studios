Drop reference cards here as .json files (one card or an array of cards per file).
Cards are INSPIRATION for the designer and engineer, never templates: the studio picks a few that
match the brief, adds some randomness so vague briefs get variety, and tells the model to combine,
bend or ignore them. Required fields: id, name, dimension ("2d" | "2.5d" | "3d"), pitch.
Optional: tags (words that match briefs), loop, systems (list), twist, pitfalls.
A card with the same id as a built-in one replaces it. Broken files are skipped.
